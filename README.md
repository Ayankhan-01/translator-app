# 🌍 Text Translator App

A modern text translator web app built with React and Tailwind CSS, integrated with RapidAPI for real-time multilingual translation.

## 🚀 Features
- Translate English text into multiple languages
- Clean and minimal UI
- Loading indicator
- Copy translated text

## 🛠 Tech Stack
- React
- Tailwind CSS
- RapidAPI

## 📦 Run Locally
npm install
npm run dev

## 🔑 Note
Add your RapidAPI key in Translator.jsx before running.
